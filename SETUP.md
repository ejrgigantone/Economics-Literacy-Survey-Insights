# Preview and publish

Nothing in this package has been committed, pushed, or published.

## Preview now

1. Extract the ZIP file.
2. Open index.html in your browser. Keep the assets folder beside it.
3. Click any chart to enlarge it; click again to return it to the collage.

The gallery includes all 41 original chart images and can load them offline.

## What is included

- README.md: the short introduction, journal-guidelines note, and linked collage.
- collage.png: a static image of the overlapping arrangement, for GitHub's README viewer.
- index.html: the interactive gallery.
- assets/: all 41 original PNG charts.

The README links to the expected GitHub Pages address for Economics-Literacy-Survey-Insights. That address is prepared for publication; this package does not enable GitHub Pages or verify that the address is live.

## Publish later, when ready

Place README.md, collage.png, index.html, and assets/ in the repository's main folder. Existing charts and R scripts can remain in place. Add and commit the changes when you are ready.

In the repository's Settings → Pages, configure deployment from the main branch and the root folder. After GitHub completes deployment, confirm the published address shown there matches the link in README.md; update both README links if necessary.

GitHub Pages setup documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit the wording

Edit the introductory paragraphs in README.md and in index.html. Both contain the note about black-and-white figures following a journal's guidelines.

The charts are the original image files. Changes to charts or their arrangement in index.html do not automatically regenerate the static collage.png.
